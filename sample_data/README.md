# Sample and Reference Data

This folder contains only synthetic or public-reference data used to demonstrate the responsible-sourcing analytics workflow.

## synthetic_supplier_farms_qgis.csv

Synthetic supplier/farm records used for the QGIS supplier-to-municipality workflow.

The supplier and farm records are not IFF operational data.

## municipality_reference.csv

Municipality-level reference data used to support geographic validation and responsible-sourcing due diligence.

The project uses public geographic and environmental reference sources where identified in the methodology.

## Data Boundary

This repository does not contain confidential IFF supplier, procurement, transaction, farm, or assurance records.

Synthetic data are used to demonstrate:

- supplier master-data linkage
- farm-to-municipality assignment
- responsible-sourcing controls
- Scope 3 validation
- geographic-risk context
- assurance-readiness logic
