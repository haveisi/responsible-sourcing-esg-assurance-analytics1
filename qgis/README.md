# QGIS Responsible Sourcing & Geographic Risk Workflow

This folder documents the geospatial component of the responsible-sourcing project.

The workflow links synthetic supplier/farm records to real Brazilian municipalities and combines them with public geographic risk indicators for due-diligence analysis.

## Main Geospatial Inputs

- IBGE municipality boundaries
- Trase soy / deforestation-related municipality indicators
- MapBiomas Alerta information
- synthetic supplier farm points
- municipality reference data

## Main Outputs

- supplier-to-municipality linkage
- municipality-level soy deforestation exposure
- MapBiomas alert context
- municipality risk classification
- due-diligence prioritization
- supplier/farm geographic validation

## Important Interpretation

Geographic risk is used as due-diligence context.

It does not establish supplier causation, wrongdoing, or direct responsibility for deforestation.

Synthetic farm points are used only to demonstrate the geospatial workflow.
